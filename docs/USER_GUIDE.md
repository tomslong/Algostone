# AlgoStone 用户使用指南

欢迎使用 AlgoStone！这是一款智能算法学习助手，帮助你通过刷题掌握算法思维。

---

## 快速开始

### 1. 启动应用

**使用 Docker (推荐)**

```bash
docker-compose up -d
```

访问: http://localhost:3001

**本地开发**

```bash
# 后端
cd backend && uvicorn app.main:app --reload --port 8001

# 前端
cd frontend && npm run dev
```

访问: http://localhost:3000

### 2. 配置 AI 设置

首次使用需要配置 AI API：

1. 点击右上角 **设置** 图标
2. 填写以下信息：
   - **API Key**: 你的 OpenAI API Key (或兼容的 API)
   - **Base URL**: API 地址 (如 `https://api.openai.com/v1`)
   - **模型名称**: 如 `gpt-4` 或 `gpt-3.5-turbo`
3. 点击保存

## 界面介绍

```
┌─────────────┬──────────────────────────────────────────────────┐
│             │  Description │ AI Assistant                      │
│   题目列表   ├──────────────────────────────────────────────────┤
│             │                                                  │
│  - Easy     │              代码编辑器 (Monaco Editor)           │

│             ├──────────────────────────────────────────────────┤

```

### 左侧：题目列表

- 按难度分类 (Easy / Medium / Hard)
- 显示 AC 状态 (绿色对勾 = 已通过)
- 搜索框快速查找题目

### 右侧：工作区

**Description 面板**
- 题目描述
- 难度标签
- 示例测试用例

**AI Assistant 面板**
- 与 AI 对话获取提示
- 支持代码分析、调试建议

**代码编辑器**
- Python 语法高亮
- 自动保存代码到数据库
- 快捷键：`Ctrl+S` 保存

**测试面板**
- Run: 运行代码测试
- Submit: 提交代码 (全部通过后记录 AC)
- 显示每个测试用例的结果

## 使用流程

### 学习新题目

1. **选择题目** - 在左侧点击题目
2. **阅读描述** - 查看 Description 面板
3. **AI 提示** - 切换到 AI Assistant 面板提问
   - "给我一些提示"
   - "帮我分析思路"
   - "解释这个算法"
4. **编写代码** - 在编辑器中实现
5. **测试验证** - 点击 Run 按钮测试
6. **提交记录** - 全部通过后点击 Submit

### 调试代码

1. **运行代码** - 查看错误信息
2. **AI 分析** - 在 AI Assistant 中描述问题
3. **修改代码** - 根据提示修改
4. **重新测试**

## 功能说明

### 代码自动保存

代码会在停止输入 1 秒后自动保存到数据库，切换题目后再回来代码依然保留。

### AC 状态

- **绿色对勾** 表示该题目已全部通过测试用例
- 状态保存在数据库中，刷新页面不会丢失
- 使用 Submit 提交成功后才会标记为 AC

### AI 对话

AI 助手支持：
- 算法思路引导
- 代码审查建议
- 错误诊断分析
- 概念解释说明

快捷操作按钮：
- "给我一些提示" - 获取解题思路
- "帮我优化代码" - 性能优化建议
- "解释这个算法" - 算法原理解释

## 常见问题

### AI 没有响应？

1. 检查设置页面是否正确配置了 API Key
2. 确认 API Base URL 和模型名称正确
3. 查看浏览器控制台是否有错误

### 代码执行失败？

1. 检查 Docker Desktop 是否运行
2. 确保有 `python:3.11-slim` 镜像
3. 查看测试面板的错误信息

### 题目加载不出来？

1. 检查后端服务是否运行
2. 确认数据库中有题目数据
3. 刷新页面重试
